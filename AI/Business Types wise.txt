🔷 1. One Template + Feature Toggle Concept

Build a single generic website template and control behavior using a configuration-driven system.

Each business instance must:

Enable/disable sections (modules)
Adjust content
Slightly adapt UI where needed

The template must not be duplicated per business.
Instead, use a feature toggle mechanism to turn sections ON/OFF and modify behavior.

Examples of controllable modules:

Booking
Pricing
Gallery
Team
Blog
Menu (restaurant only)
Listings (real estate replaced → not needed now)

The system should allow:

Reordering sections
Hiding unused sections
Switching between internal/external integrations (e.g., booking)

🔷 3. Business Type Variable (Core Driver)

Introduce a businessType variable that drives:

Section visibility
Feature activation
UI variations
Theme selection

This variable must act as the primary switch for template behavior.

The system should allow:

Default config per business type
Ability to override per client
🔷 4. Theme System (Very Important)

Define a theme configuration per business type.

Each theme should control:

Primary & secondary colors
Typography (font family)
Button styles
Section styling (soft, bold, luxury, minimal, etc.)

🔥 Final Instruction

Design the system so that:

👉 Template = fixed
👉 Behavior = driven by config (businessType + features + theme)

The goal is:

One system
Multiple business outputs
Easy onboarding of new business types without redesign
