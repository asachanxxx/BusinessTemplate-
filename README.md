# SMB Website Template

A generic, fully reusable React + TypeScript website template for small-to-medium businesses.

Set a single `businessType` field to deploy a fully-themed site for any business type — no code changes needed.

## Business types

`generic` | `restaurant` | `salon` | `gym` | `cleaning` | `auto` | `clinic` | `photography` | `coaching` | `hotel` | `retail`

## Quick start

```bash
cd Template
npm install
npm run dev
```
